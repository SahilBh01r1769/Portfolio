02 / About

A broad engineering base, with AI/ML as the direction.

I enjoy moving between the model, the code around it and the way the final system is used. That is why the projects here cover more than one narrow area.

I’m interested in work where the technical challenge does not end once a model produces an output. I like thinking about whether the data is reliable, how the pieces of a system talk to each other, what should happen when something fails, and whether the result is understandable to the person using it.

My projects have taken me through industrial time series, computer vision, NLP, AWS serverless systems and data visualisation. I’m still early in my career, so I see that range as useful: it has helped me understand which parts of engineering I want to go deeper into instead of specialising too early.
